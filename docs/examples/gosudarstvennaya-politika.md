# Сценарий: Анализ Государственной Политики

> Как исследователи, государственные аналитики и общественные организации могут использовать `mcp-russia` для оценки эффекта государственных программ на основе данных из нескольких публичных систем.

---

## Проблема

Оценка государственной политики требует совмещать данные о реализации программы, контрактах и расходах с результативностью по социальным, экономическим и отраслевым показателям.

| Измерение | Необходимые источники |
|-----------|----------------------|
| Вложенные ресурсы | Портал бюджетной системы, контрольно-счётные органы субъектов РФ |
| Реализация | ЕИС zakupki.gov.ru, публикация в Официальном интернет-портале правовой информации |
| Результаты здравоохранения | Реестры Минздрава, Росстат |
| Экономические результаты | Банк России, Минфин, Росстат |
| Образовательные результаты | Росстат (агрегаты), Минпросвещения |
| Правовой контекст | Картотека арбитражных дел, ГАС «Правосудие», судебная практика |
| Законодательный контекст | Государственная Дума, Совет Федерации |

**`mcp-russia` сводит эти источники в единый аналитический интерфейс.**

---

## Анализ 1: Первичная медико-санитарная помощь и результативность

### Вопрос

Как проверить, дают ли вложения в первичную медико-санитарную помощь заметный эффект по базовым показателям здоровья на уровне муниципалитетов?

### Сценарий анализа

**1. Определение охвата участковой службой по муниципалитетам**

> Промпт: "Сколько участков первичной медико-санитарной помощи обслуживают население в районах Республики Татарстан? Сравните с численностью населения"

```
API: minzdrav_poisk_med_organizatsiy(region="16", tip="polyclinika")
     rosstat_informatsiya_o_regionye(region="16") → chislennost_naseleniya
```

**2. Расходы на первичное звено здравоохранения**

> Промпт: "Какова доля расходов на первичную медико-санитарную помощь в общих расходах на здравоохранение по каждому району?"

```
API: budget_rashody_subekta(region="16", razdel="09", podrazdel="01") *(планируемый модуль «Бюджетная система»)*
```

**3. Показатели результативности**

> Промпт: "Сравните младенческую смертность и ожидаемую продолжительность жизни в районах с наибольшим и наименьшим охватом участковой службой"

```
API: rosstat_pokazateli_rosstata(indikatory="zdorovye", uroven="municipalitet")
```

**4. Межбюджетные трансферты на здравоохранение**

> Промпт: "Какой объём межбюджетных трансфертов на здравоохранение получил каждый район Республики Татарстан в 2024 году?"

```
API: budget_transformacii(region="16", razdel="09") *(планируемый модуль «Бюджетная система»)*
```

### Как связываются данные

```
Охват участковой службой (Минздрав)   +   Расходы на душу населения (Казначейство)
              ↓                                      ↓
Младенческая смертность (Росстат) ←→ Трансферты на здравоохранение (Бюджетная система)
```

### Что показывает такой анализ

| Группа | Охват участковой службой | Младенческая смертность | Расходы на здравоохранение/душу |
|--------|-------------------------|------------------------|-------------------------------|
| Верхние 20% (наибольший охват) | > 90% | 4,2 на 1000 | 18 500 руб. |
| Средние 60% | 50–90% | 6,1 на 1000 | 13 200 руб. |
| Нижние 20% (наименьший охват) | < 50% | 8,7 на 1000 | 9 400 руб. |

**Отчётливая корреляция: больший охват участковой службой → ниже младенческая смертность.**

## Анализ 2: Специальные перечисления и политическое распределение

### Вопрос

Как отличить социально обоснованное распределение межбюджетных трансфертов от политически мотивированного?

### Сценарий анализа

**1. Картирование специальных перечислений по муниципалитетам**

> Промпт: "Какие муниципалитеты получили наибольший объём специальных перечислений в 2024 году?"

```
API: budget_spetsperechisleniya(god=2024) *(планируемый модуль «Бюджетная система»)*
```

**2. Расчёт на душу населения и сравнение с индикаторами**

> Промпт: "Сопоставьте объём специальных перечислений на душу населения с индексом человеческого развития (ИЧР) муниципалитетов"

```
API: budget_spetsperechisleniya *(планируемый)* + rosstat_informatsiya_o_regionye + rosstat_pokazateli_rosstata
```

**3. Проверка целевого использования ресурсов**

> Промпт: "На какие цели муниципалитеты направили специальные перечисления? Были ли проведены конкурентные закупки?"

```
API: zakupki_poisk_kontraktov(perechisleniya) + rosaudit_ispolnenie_byudzheta
```

**4. Анализ паттерна распределения**

> Промпт: "Специальные перечисления направляются в муниципалитеты с опорой на социальную необходимость или распределяются пропорционально?"

```
API: budget_spetsperechisleniya *(планируемый)* + rosstat_pokazateli_rosstata(sotsialno-ekonomicheskie)
```

### Типовой вывод

```
РАСПРЕДЕЛЕНИЕ СПЕЦИАЛЬНЫХ ПЕРЕЧИСЛЕНИЙ — 2024

По ИЧР муниципалитета:
  ИЧР очень высокий (>0,800):  3 200 руб./душу
  ИЧР высокий (0,700–0,799):   5 400 руб./душу
  ИЧР средний (0,600–0,699):   8 700 руб./душу
  ИЧР низкий (<0,600):         6 100 руб./душу

⚠️ Муниципалитеты со средним ИЧР получают БОЛЬШЕ, чем
   муниципалитеты с низким ИЧР — что указывает на возможный
   политический, а не социальный критерий распределения.

По политическому выравниванию:
  Опорные муниципалитеты:      7 800 руб./душу
  Оппозиционные:               4 500 руб./душу
  ⚠️ Разница в 73 % в пользу опорных муниципалитетов.
```

## Анализ 3: Экологический ущерб, санкции и исполнение

### Вопрос

Как сопоставить экологический ущерб, наложенные санкции и реальное исполнение штрафов, чтобы увидеть разрыв между выявлением нарушения и фактическим наказанием?

### Сценарий анализа

**1. Данные о вырубке лесов**

> Промпт: "Каков объём вырубки лесов по субъектам РФ в Сибирском федеральном округе за последние 5 лет?"

```
API: rosprirodnadzor_lesnaya_okhrana(region="sibir", period="5y") *(инструмент недоступен)*
```

**2. Штрафы и санкции**

> Промпт: "Сколько организаций привлечено к ответственности за незаконную вырубку? Были ли уплачены штрафы?"

```
API: rosaudit_poisk_narusheniy(narushenie="nezakonnaya_vyrubka")
     rosaudit_info_auditorskogo_zaklyucheniya(tema="lesnoe_khozyaistvo")
```

**3. Судебные дела**

> Промпт: "Сколько дел о нарушениях в области охраны окружающей среды рассмотрено судами за последние 5 лет?"

```
API: kad_arbitrazh_poisk_del(tema="ekologicheskoe_pravonarushenie")
     kad_arbitrazh_poisk_del(term="nezakonnaya_vyrubka obvinenie")
```

**4. Затронутые водные ресурсы**

> Промпт: "Снизился ли уровень водохранилищ в регионах с наибольшим объёмом вырубки лесов?"

```
API: rosvodresursy_info_vodokhranilishcha(region="sibir")
```

### Кросс-ссылка

```
Вырубка лесов (Росприроднадзор)
    ↓
Наложенные штрафы (Бюджетная прозрачность) → Уплаченные штрафы? (Казначейство)
    ↓                                              ↓
Судебные дела (ГАС «Правосудие») → Обвинительные решения (Судебная практика)
    ↓
Воздействие на водные ресурсы (Росводресурсы)
```

## Анализ 4: Налоговая реформа — Прогноз влияния по субъектам РФ

### Вопрос

Налоговая реформа меняет распределение доходов между субъектами РФ. Какие выигрывают, какие теряют?

### Сценарий анализа

**1. Текущие доходы по субъектам**

> Промпт: "Каковы налоговые доходы по каждому субъекту РФ за последние 3 года?"

```
API: budget_dokhody_subekta(period="3y") *(планируемый модуль «Бюджетная система»)*
     rosstat_pokazateli_rosstata(dokhody_byudzhetov)
```

**2. ВРП по субъектам**

> Промпт: "Каков ВРП и ВРП на душу населения каждого субъекта?"

```
API: rosstat_informatsiya_o_regionye(region="all", pokazatel="vrp_na_dushu")
```

**3. Законодательное оформление**

> Промпт: "Как голосовали депутаты Государственной Думы по законопроекту о налоговой реформе? Как проголосовала каждая региональная делегация?"

```
API: gosduma_golosovaniya(sozyv=..., ogranichenie=...)
```

**4. Публикации нормативных актов**

> Промпт: "Найдите в Официальном интернет-портале правовой информации нормативные акты, регулирующие налоговую реформу"

```
API: publikatsii_poisk_aktov(term="nalogovaya reforma regulirovanie")
```

## Анализ 5: Публичные закупки — Эффективность и конкурентность

### Вопрос

Публичные закупки проводятся на конкурентной основе или доминируются ограниченным числом поставщиков?

### Сценарий анализа

**1. Данные о закупках**

> Промпт: "Сколько закупок проведено федеральными органами власти в 2024 году? Каков их общий объём?"

```
API: zakupki_poisk_kontraktov(god=2024, uroven="federalny")
```

**2. Концентрация рынка**

> Промпт: "Кто 20 крупнейших поставщиков федеральных органов власти? Какую долю от общего объёма они составляют?"

```
API: zakupki_info_postavshchika(top=20, uroven="federalny")
```

**3. Конкурентность закупок**

> Промпт: "Каково среднее число заявок на одну закупку? Сколько закупок получили только одну заявку?"

```
API: zakupki_sposoby_zakupok(zayavki="sravnenie")
```

**4. Санкции и нарушения**

> Промпт: "Сколько поставщиков федеральных органов власти включены в реестр недобросовестных поставщиков (РНП)?"

```
API: zakupki_gov_ru_rnp(uchastniki="postavshchiki_federalnykh") *(планируемый — функционал РНП)*
```

## Каркас Для Анализа Государственной Политики

`mcp-russia` позволяет выстроить системный сценарий исследования:

```
1. ЗАКОНОДАТЕЛЬНЫЙ КОНТЕКСТ
   └── Государственная Дума/Совет Федерации: каким законом создана программа?

2. РЕСУРСЫ (ВХОД)
   └── Бюджетная система/Казначейство: какой объём средств вложен?

3. РЕАЛИЗАЦИЯ (ПРОЦЕСС)
   └── ЕИС zakupki.gov.ru: как исполнялись контракты?
   └── Официальный интернет-портал правовой информации: какие нормативные акты?

4. РЕЗУЛЬТАТЫ (ВЫХОД)
   └── Росстат/Минздрав/Банк России: какие индикаторы изменились?

5. ОТЧЁТНОСТЬ И КОНТРОЛЬ (ОТВЕТСТВЕННОСТЬ)
   └── Контрольно-счётные органы: выявлены ли нарушения?
   └── ГАС «Правосудие»: возбуждены ли дела?
   └── Избирательная система: кто получил политическую выгоду?
```

## Следующие шаги

- привязать примеры к конкретным кейсам по программам лекарственного обеспечения, национального проекта «Здравоохранение» и экологического мониторинга;
- добавить недостающие инструменты: «Бюджетная система» (budget_rashody_subekta, budget_transformacii, budget_spetsperechisleniya, budget_dokhody_subekta), `rosprirodnadzor_lesnaya_okhrana`, функционал РНП в модуле «Закупки».

### Автоматизация Через `splanirovat_zapros`

> Промпт: "Хочу оценить влияние программы льготного лекарственного обеспечения на доступность медикаментов. Составь план запросов"

`mcp-russia` строит полный план исследования: набор инструментов, порядок вызовов и зависимости между шагами.
