# ОБРАЗЕЦ: АКТ

## Структура документа

```
[Наименование организации]

АКТ

[дата]    № [номер]    [город]

[Заголовок — о чём акт]

        [Преамбула: основание составления акта]

        Комиссия в составе:

        Председатель — [должность, И.О. Фамилия]
        Члены комиссии:
        — [должность, И.О. Фамилия]
        — [должность, И.О. Фамилия]

        составила настоящий акт о нижеследующем:

1. [Факт первый]
2. [Факт второй]

        [Заключение / выводы]

Подписи:

Председатель     __________     [И.О. Фамилия]

Члены комиссии:
               __________     [И.О. Фамилия]
               __________     [И.О. Фамилия]
```

## Правила

1. Акт — документ, фиксирующей факты, события, действия
2. Составляется комиссией (не менее 3 человек)
3. Факты излагаются последовательно и объективно
4. Акт подписывается всеми членами комиссии
5. Утверждается руководителем организации
